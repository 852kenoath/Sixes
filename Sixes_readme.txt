# Sixes

Sixes is an original typeface designed by Kenneth Chow.

Inspired by geometric and hexagonal forms, Sixes combines a distinctive technical appearance with clean, readable letterforms. The typeface was created as a custom font project and is distributed in TrueType format (.ttf).

## Installation

### Windows
1. Download the `.ttf` file.
2. Right-click the file.
3. Select **Install** or **Install for all users**.

### macOS
1. Double-click the `.ttf` file.
2. Click **Install Font** in Font Book.
